# B2 First Trainer

Webapp estática, adaptable a móvil y ordenador. Incluye práctica original de Use of English, Grammar & Vocabulary, Listening con guion, Writing, Speaking, mini mock exam y seguimiento local.

## Probar
Abre `index.html` en un navegador. Para instalarla como app y usar el modo offline, publícala mediante HTTPS (por ejemplo GitHub Pages) y ábrela en Safari/Chrome.

## Publicar con GitHub Pages
1. Descomprime este ZIP.
2. Sube `index.html`, `manifest.webmanifest` y `sw.js` a un repositorio de GitHub.
3. En el repositorio: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Abre la URL que GitHub Pages genere en el móvil.
5. iPhone: Safari → Compartir → Añadir a pantalla de inicio. Android: Chrome → menú → Instalar aplicación / Añadir a pantalla de inicio.

## Importante
- El progreso se guarda en el almacenamiento local del navegador/dispositivo; no se sincroniza automáticamente.
- Listening usa transcripciones, no audio grabado.
- Writing y Speaking incluyen tareas y autoevaluación, no una corrección oficial Cambridge.
- Contenido de práctica original; no reproduce en bloque material protegido de terceros.
